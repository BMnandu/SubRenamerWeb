# v1.1 调轴任务 API 迁移

## 行为变化

旧版 `POST /api/sync` 会把 FFsubsync 输出直接写入视频目录。新版保留该路由，但请求进入安全任务服务：

1. 先调用与 `/api/sync/plans` 相同的路径和唯一命名校验；
2. 为任务创建 `/work/<taskId>/`；
3. 只在 `output/` 中生成候选字幕；
4. 返回总体状态、逐项状态、偏移、帧率比例、质量原因和有限日志；
5. 不移动或删除输入字幕；只有后续显式 `commit` 才写入正式媒体目录。

旧前端使用的 `{ "items": [...] }` 请求仍然兼容，默认模式为 `video_global`。推荐新调用方显式传入 `defaultMode` 和 `options`。

## 请求示例

```json
{
  "defaultMode": "video_global",
  "options": {
    "rejectLowQuality": true,
    "maxQualityOffsetSeconds": 30,
    "maxFramerateDeviation": 0.1,
    "timeoutSeconds": 900,
    "referenceStream": "a:0"
  },
  "items": [
    {
      "itemId": "episode-01-chs",
      "key": "01",
      "video": "/media/Show/Show S01E01.mkv",
      "subtitle": "/uploads/session/Show.01.chs.ass",
      "language": "zh-Hans"
    }
  ]
}
```

字幕参考模式需把单项 `mode` 设为 `subtitle_reference`，并提供 `referenceSubtitle`。分段模式需显式使用 `video_split`，可通过 `options.splitPenalty` 调整参数；它不会被默认启用。

## 状态

总体状态包括：`queued`、`running`、`awaiting_commit`、`completed`、`completed_with_errors`、`failed`、`cancelled`、`timed_out`。

逐项状态包括：`planned`、`running`、`succeeded`、`rejected_low_quality`、`failed`、`cancelled`、`timed_out`、`committed`、`rolled_back`。

`awaiting_commit` 表示 staging 结果已经生成并通过本阶段校验。`completed` 表示所有可提交项均已进入媒体目录；`rolled_back` 项保留 staging，可再次提交。

## 提交与回滚

默认提交请求不会覆盖现有字幕：

```json
{ "allowOverwrite": false }
```

目标存在时该项返回 `conflict`，HTTP 响应为 `409`。同一批其他无冲突项可能已经提交，因此调用方必须读取逐项结果，不应仅依赖 HTTP 状态判断整批是否产生写入。

显式设置 `allowOverwrite: true` 时，系统先把旧目标原子复制到任务 `backup/`，记录原文件和提交文件的 SHA-256，再把 staging 候选复制到目标目录的临时文件并原子改名。

回滚只处理状态为 `committed` 的项：

- 提交前没有目标：仅当当前目标哈希仍等于本任务提交内容时删除；
- 提交前已有目标：校验当前目标和备份哈希后恢复备份；
- 目标或备份被移动、删除或修改：返回 `conflict`，不执行破坏性操作；
- 重复提交和重复回滚分别返回 `already_committed`、`already_rolled_back`。

## 路由

- `POST /api/sync` 或 `POST /api/sync/tasks`：创建任务；队列满返回 `429`。
- `GET /api/sync/{taskId}/status` 或 `GET /api/sync/tasks/{taskId}`：查询任务。
- `POST /api/sync/{taskId}/cancel` 或 `POST /api/sync/tasks/{taskId}/cancel`：请求取消。
- `POST /api/sync/{taskId}/commit` 或 `POST /api/sync/tasks/{taskId}/commit`：提交候选结果。
- `POST /api/sync/{taskId}/rollback` 或 `POST /api/sync/tasks/{taskId}/rollback`：回滚本任务提交。

任务日志有长度上限；取消和超时会终止 Python/FFmpeg 子进程树，并清除尚未完成的临时输出。
