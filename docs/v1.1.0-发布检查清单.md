## 创建版本

以下操作必须取得明确发布确认后执行：

```bash
git switch main
git pull --ff-only
git tag -a v1.1.0 -m "SubRenamerWeb v1.1.0"
git push origin v1.1.0
```

创建标签后核验：

- [ ] 标签指向已通过全部门禁的 `main` 提交。
- [ ] Docker Hub 已发布 `1.1.0` 和 `1.1` 多架构标签。
- [ ] 如创建 GitHub Release，正文与 `CHANGELOG.md` 一致。
- [ ] 未把“镜像已发布”误写成“NAS 已部署”。

## 生产部署边界

- [ ] NAS 部署必须作为独立任务取得授权。
- [ ] 部署前记录当前运行版本、挂载路径、UID/GID 和回滚方式。
- [ ] 使用测试媒体验证后，才能更新生产运行事实文档。
